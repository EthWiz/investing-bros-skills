# Episode artwork and YouTube thumbnails

Load `investing-bros-show` first. Its Brand section owns the current identity, exact
host spelling, selected reference assets and reusable templates. Follow its
`references/brand/workflow.md`; do not use the retired cinematic prompts.

## Inputs
Use the supplied topic, exact headline and episode number. If the headline is missing,
read the transcript/chapters and offer 2-3 truthful concise options. Never replace an
already supplied headline silently. The real episode content determines the subject.

## Steps
1. Choose the relevant selected reference from investing-bros-show. Use the exact
   selected image when editing. Inspect it before sending it to the image tool.
2. Read that skill's brand rules and choose a layout: square episode, wide thumbnail
   or vertical cover. Wide/vertical templates are proposed adaptations requiring review.
3. Fill its reusable prompt: one clear engraved topic illustration, cream/mustard title
   strips, navy background, exact supplied copy, number and current host credit.
4. Generate with the available image tool, or hand back a complete prompt if requested.
   Do not invent a font match, company logo, factual claim or host portrait.
5. Check Hebrew spelling, RTL punctuation, real dimensions and small-size legibility.
   For tokenization keep the user-selected digital grids on detached certificate tiles.
6. Save requested finished artwork to `promo/`. Use `thumbnail-פרק-N.jpg` for the
   finished wide thumbnail when exported as JPEG. Do not merely rename a PNG to JPG.

## Hand back
Show the artwork or filled prompt, supplied headline and any proposed alternatives,
actual format/dimensions and unresolved limitations. Keep new layouts labeled as
adaptations until reviewed. Publication remains subject to Amitai's explicit OK.
