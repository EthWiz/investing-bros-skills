# Cover and thumbnail rules (Amitai, Oct 2026)

Applies to the square episode cover, the 16:9 YouTube thumbnail and Shorts covers.
Overlaps PR #23 (new cover structure); if both are merged, this file is the
taste checklist and #23's layouts are the geometry.

## Taste
- **Elegant but engaging.** Clean, breathing room, one clear focal point.
  Not loud or busy (episode 8 options A/B/C were rejected as too loud), and not
  so minimal it's empty (v3a/v3b were too calm). When unsure, keep the previous approved cover.
- **One bold main visual** with topic-appropriate props (gold bars for gold, reactor for nuclear...).
- **Podcast logo bottom-right**, high contrast against the background.
- **No hosts' name strip.**
- **"SpaceX" in Latin letters**, styled like the SpaceX wordmark in thumbnails. Titles stay Hebrew otherwise.

## Deliverables
- The YouTube thumbnail uses **the same layout** as the square cover (same visual, title, logo spot), re-flowed to 1280x720.
- Save both in the episode's Drive folder (`פרק N/`), next to the transcript.
- Show Amitai before using; he picks.

## When the Mac / Codex is unreachable
Don't wait on it. Generate the art with the agent's own image tool (text-free
prompt), set the Hebrew yourself with Pillow and the brand fonts, then **check the
Hebrew by eye** at full size and at ~200 px: letters right-to-left, "?" on the left,
nothing clipped, no stray generated letters. Note in the hand-off that it wasn't made with Codex.
