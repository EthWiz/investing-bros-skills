# YouTube Studio checklist

Use the browser profile for the Editor account named in `investing-bros-show`.

## Before selecting a file
1. Open Studio and use the avatar's **Switch account** action.
2. Confirm the active channel is **אחים להשקעות**, not the Editor account's empty
   personal channel **Grok Bot**. Studio edit links on this box often reopen as
   **Grok Bot**, so repeat this check for every upload or edit task, even when a
   direct Studio URL initially looks correct.
3. The brand-channel owner must complete phone verification before videos longer
   than 15 minutes or custom thumbnails can be uploaded. An Editor cannot do this.
   If the verification form shows a US placeholder such as `(201) 555-5555`,
   switch the country to Israel or enter the number with the `+972` country code.

## Details
- Paste the approved title and the YouTube description as plain text, with no
  RedCircle RTL marks. When copying Hebrew through a local server, serve a UTF-8
  HTML page containing `<meta charset="utf-8">`; plain `.txt` served this way has
  arrived garbled on this box.
- Include the clean per-episode Spotify URL line required by the upload skill.
  YouTube descriptions cannot embed a logo or image; use the `🎧` marker only.
- Audience: **No, it's not made for kids**.
- Visibility: **Private** until Amitai explicitly approves publication.
- Video language: Hebrew.
- Thumbnail: use only the approved final image in `promo/`. If the custom-thumbnail
  control is unavailable, report the channel-verification blocker.
- Altered-content answer: answer truthfully for the video. A generated thumbnail
  alone does not make a real-recording episode altered video content.
- Leave episode-specific tags, category, playlist, cards and recording location
  unchanged unless Amitai supplied them or the channel already has an established
  default. Do not invent metadata.

## Checks and elements
- Wait for YouTube's copyright check. Report a claim; do not dispute it.
- Add an end screen only when a suitable published episode, playlist or subscribe
  target exists.
- Save as **Private**, then confirm the Studio row says Private and HD processing
  finishes.
- Open the private watch page as the Editor and check title, description direction,
  increasing chapter times, the `00:00` teaser chapter and the progress-bar chapters.
